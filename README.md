# Sir Smith Cleaning Company

## Description
Welcome to the Sir Smith Cleaning Company app! This is a web application built with the MERN stack (MongoDB, Express, React, Node.js) that allows users to book cleaning services easily.

## Features
- View a list of available cleaning services.
- Book a service by submitting your personal details.
- Simple and user-friendly interface.

## Getting Started
